# DDrace 3D 原型

挤出式 2.5D：原版 DDNet 的 tile 地图沿 Z 轴挤出 5 条车道，物理和钩绳逻辑保持 2D 原样，  
只有走位与碰撞新增 z 维度。零构建，three.js 与贴图已内置在 `vendor/`。

## 运行

```bash
python -m http.server 8117
# 打开 http://127.0.0.1:8117/index.html
```

调试用的参数：`?view=first` 直接进第一人称。

## 操作

| 键          | 作用                |
| ---------- | ----------------- |
| A / D      | 左右（第一人称下相对视角）     |
| W / S      | 横移（管道纵深）；第一人称下是前后 |
| 空格         | 跳跃 / 空中再按一次二段跳    |
| **鼠标右键按住** | 出钩，松开脱钩           |
| V          | 切换第一 / 第三人称       |
| R          | 重生                |

第一人称：点击画面锁定鼠标；锁定失败时把鼠标移到屏幕边缘也能持续转向（yaw 不做任何 clamp，可以转满 360°）。

## 物理常数：全部对照本机 DDNet 源码

来源：`/d/ddrace/src/game/tuning.h` + `/d/ddrace/src/game/gamecore.cpp`  
（SERVER_TICK_SPEED = 50，PhysicalSize = 28px，1 tile = 32px）

| tuning.h 原始值                      | 本项目（tile/s 或 tile/s²）      |
| --------------------------------- | -------------------------- |
| gravity 0.5                       | 39.06                      |
| ground_jump_impulse 13.2          | 20.625                     |
| air_jump_impulse 12.0             | 18.75                      |
| ground_control_speed 10           | 15.625                     |
| air_control_speed 250/50 = 5      | 7.8125                     |
| ground_control_accel 100/50 = 2.0 | 156.25                     |
| air_control_accel 1.5             | 117.19                     |
| ground_friction 0.5（乘法）           | 指数 k = ln(0.5)×50 = 34.66  |
| air_friction 0.95（乘法）             | 指数 k = ln(0.95)×50 = 2.564 |
| hook_length 380                   | 11.875                     |
| hook_drag_accel 3.0               | 234                        |
| hook_drag_speed 15                | 23.4375                    |

实测结果（`node test/phys.test.mjs`，15 项）：跳高 5.62 格、二段跳 9.60 格、平地跳距 16.7 格、松手 0.17s 剩速 0.05、棱角不侧滑。

三条只能靠源码确认、最容易做错的规则：

1. **摩擦是乘法不是减法**（`m_Vel.x *= Friction`），所以松手几乎瞬停，不是滑行。
2. **SaturatedAdd**：速度超过上限时按方向键既不加速也不减速。所以空中（上限只有地面一半）几乎改不了方向。
3. **钩子不是刚性绳，也不是射线**。它是飞行物：以 `hook_fire_speed` 80px/tick（125 tile/s）飞出去，撞到实体才抓住，飞满 380px(11.875 格) 没撞到就缩回 —— 所以够不到东西时也会有出钩动作。抓住后是每 tick 朝锚点加 3.0 的速度增量，距离 < 46px 不拉，向下的拉力只给 30%。
4. **DDNet 没有冲刺**，所以这里没有 dash。移动只有走、跳、二段跳、钩。

## 碰撞形状：方盒，不是球

`PhysicalSize` = 28px，源码 `collision.cpp` 的 `MoveBox` 是 28×28 矩形扫掠。  
用球体做碰撞会在方块棱角产生斜向推出，表现出来就是**站在边缘脚滑**——原版没有这个机制。  
现在玩家是半边长 0.4375 的 AABB，只沿移动轴推出，站在棱角上不会漂移（测试第 15 项覆盖）。

## 贴图（全部来自游戏资源，没有手绘）

| 部件 | 来源                                              | 坐标                                     |
| -- | ----------------------------------------------- | -------------------------------------- |
| 方块 | `%APPDATA%/DDNet/assets/entities/FunClient.png` | 64×64 槽位，(64,0)                        |
| 钩头 | `data/game.png` 的铁链+灰箭头                         | (112,0) 起 64×32                        |
| 锁链 | `data/game.png` 的链环                             | (64,0) 起 64×32，沿绳长平铺                   |
| 小人 | `data/skins/default.png` 的 body + 眼睛            | body (14,14) 起 64×64，眼 (218,8) 起 16×16 |

注意两个坑：

- `FunClient.png` 是 **64×64 槽位**，原点有 64px 透明边距，不是 32px 网格。
- 钩子图标是 `game.png` 的箭头；`FunClient.png` 的 `(64,64)` 那把剑是**无限钩 buff**，别用错。
- `default.png` 的 tee 是拆成 body / eyes / feet 的部件图，需要合成，不是现成的一帧小人。

换皮肤：替换 `vendor/skin.png`，body 和眼睛坐标可能要跟着调。

## 准星

- **绿色 = 这个方向钩得到**（射线在 hook_length 内命中实体），红色 = 钩不到。
- 第三人称跟随鼠标，第一人称固定在屏幕中心。
- 系统光标已隐藏（`cursor: none`），统一用自己的准星。

## 右键

右键出钩。为了避免弹菜单 / 触发浏览器手势，做了三层拦截：  
`window` 捕获阶段干掉 `contextmenu`、`auxclick`、`pointerdown`、`mousedown` 全部 preventDefault。  
第一人称还会申请指针锁，锁定时浏览器本来就不弹右键菜单。

如果仍然出现「无效手势」，那是**鼠标驱动层**（罗技 / 雷蛇等驱动的手势功能）或浏览器扩展，  
网页拦不到，需要在驱动软件里关掉右键手势。

## 改地图

`src/map.js` 的 `build()`，一行一块：

```js
region('solid', x0, y0, lane0, x1, y1, lane1)   // 实体
region('hazard', x0, y0, lane0, x1, y1, lane1)  // 死亡区
```

坐标单位就是 tile，与 DDNet 地图的 tile 网格一一对应；`lane` 是 0..4，可以只占部分车道（窄门就是这么做的）。

关卡按 DDNet 物理标定：坑宽 ≤ 16.7 才能跳过去，台阶级差 ≤ 5，超过 5.6 必须挂钩。

## 设计上的两个关键决定

1. **第三人称钩绳锁定在玩家当前深度平面内**（`tryHook` 里把命中点 z 投影到 `player.z`）。  
   否则射线命中的是相机侧表面，玩家会被拽到别的车道。
2. **钩绳锚点沿命中面法线外推一个身位**，避免收绳把玩家拽进方块内部卡死。  
   第一人称下保留真实 3D 锚点，因为准星本身就是玩家选的方向。
